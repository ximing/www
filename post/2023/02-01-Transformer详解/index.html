Transformer 详解：自注意力、多头与位置编码

📅2023-02-01

#大模型

本文是「零基础学大模型原理」系列的第 4 篇。这个系列记录一个没有任何机器学习背景的工程师，在 ChatGPT 发布之后从零补原理的过程。

  • 神经网络入门：从感知机到反向传播
  • 词怎么变成向量：从 one-hot 到 Word2Vec
  • Transformer 之前：RNN、seq2seq 与注意力机制
  • Transformer 详解：自注意力、多头与位置编码（本文）

上一篇结尾留了两个问题：2017 年的 Attention is All You Need 去掉循环结构后，顺序信息从哪里来？逐词生成如何实现？这两周我读完了这篇论文。论文本体只有十几页，信息密度较高。我结合两份材料阅读：Jay Alammar 的 The Illustrated Transformer 用图解释结构，Harvard NLP 的 The Annotated Transformer 用 PyTorch 逐行实现，并对照代码核对每个张量的形状。本文记录阅读结果。前置是上一篇，记得 Bahdanau 注意力的打分、softmax、加权求和三步就够。

自注意力中的查询来源

Bahdanau 注意力中，解码器状态发起打分，编码器各位置的隐状态提供被查询的信息。Transformer 论文中的自注意力（self-attention）让查询方和被查询方来自同一个序列。每个位置以自己的表示生成查询，与序列中所有位置（包括自身）的键计算分数，再按分数对各位置的值加权，得到新的表示。

这项改动回应了上一篇中 RNN 的两个限制。第一，任意两个位置之间的依赖路径长度为一步。RNN 中，第 1 个词的信息需要经过中间时刻传到第 50 个词；自注意力中，第 50 个词可以直接与第 1 个词计算点积。第二，整层计算可以并行。每个位置的新表示只依赖这一层的输入向量，不依赖其他位置先完成计算，因此 n 个位置的打分和加权可同时进行。自注意力层不再有 RNN 在时间步上的串行依赖。

Q、K、V：查询、键与值

同一个位置的输入表示通过三个可学习的线性映射，投影为三类向量：

  • Query（查询）：当前位置要匹配什么信息。
  • Key（键）：当前位置被检索时用于匹配的信息。
  • Value（值）：当前位置在加权汇聚时提供的内容。

这三类向量组成一次加权检索：query 与每条记录的 key 计算匹配分数，再按分数对对应的 value 加权。这里用点积计算分数；在向量长度相同且已归一化时，方向越一致，点积越大。

为什么需要三个投影，而不直接让词向量互相计算？我当时的理解是，查询目标、匹配线索和汇聚内容对应不同需求。代词的 query 可以用于匹配其指代的名词；它作为被查询对象时的 key，以及被加权汇聚的 value，可以使用不同表示。使用同一个向量时，三个角色只能共用一套表示。映射矩阵 WQ​、WK​、WV​ 是训练参数，训练过程决定各自的投影方式。

打分、缩放、softmax：注意力的完整公式

把整句所有位置的 q、k、v 分别堆成三个矩阵 Q、K、V，一整层自注意力就是一个式子：

Attention(Q,K,V)=softmax(dk​​QK⊤​)V

QK⊤ 一次矩阵乘法算出所有位置两两之间的打分，得到一个 n×n 的矩阵，第 i 行第 j 列是位置 i 对位置 j 的分数；除以 dk​​ 缩放；softmax 按行归一化，每行变成一组和为 1 的权重；最后乘 V，按权重对所有位置的 value 加权求和。整层由两次矩阵乘法和一个 softmax 构成，不包含循环。

除以 dk​​ 的理由需要单独说明。论文假设 q 和 k 的各分量独立、均值为 0、方差为 1，则点积的方差随维度 dk​ 线性增长。维度增大时，打分的量级也会增大，softmax 可能进入饱和区，输出接近 one-hot，梯度变小。除以 dk​​ 后，打分的方差回到 1 附近。这个统计论证依赖的前提我当时无法逐一验证；softmax 输入过大导致梯度变小的现象，与第 1 篇手算过的 sigmoid 导数 σ(z)(1−σ(z)) 所示的饱和问题类似。

手算一遍：三个词的完整注意力矩阵

以「我 爱 吃苹果」的三个位置为例计算。为便于手算，将向量设为 2 维，并令 WQ​=WK​=WV​ 都等于单位阵，因此 q=k=v=x。实际模型中的三个投影由训练得到；这里使用单位阵，仅用于展示注意力计算。

三个位置的向量：

  • 我：x1​=[1,0]
  • 爱：x2​=[0,1]
  • 吃苹果：x3​=[1,1]

dk​=2，dk​​≈1.41。以位置 3（吃苹果）为查询方，先算它和三个 key 的点积：

q3​⋅k1​=1,q3​⋅k2​=1,q3​⋅k3​=2

除以 1.41，得 0.71、0.71、1.41。做 softmax：e 的幂分别是 2.03、2.03、4.11，合计 8.17，归一化后：

α3​=[0.25, 0.25, 0.50]

用这组权重对三个 value 加权求和：

o3​=0.25×[1,0]+0.25×[0,1]+0.50×[1,1]=[0.75, 0.75]

位置 3 的新表示就是 [0.75, 0.75]。按同样流程计算位置 1 和位置 2。位置 1 的缩放后打分是 0.71、0、0.71，位置 2 是 0、0.71、0.71。得到的注意力矩阵如下，行是查询方，列是被查询方：

​0.400.200.25​0.200.400.25​0.400.400.50​​

每行之和为 1。三个输出分别是 o1​≈[0.80,0.60]、o2​≈[0.60,0.80]、o3​≈[0.75,0.75]。

每个位置的输出是全句 value 的加权组合，组合比例由打分决定。词向量经过自注意力后形成依赖上下文的表示。第 2 篇结尾的「一词多义怎么办」在这里有了机制上的处理方式：「吃苹果」里的「苹果」和「苹果公司」里的「苹果」会与不同上下文中的 Q、K、V 共同计算，因此输出表示可以不同。例中的向量是人为设定的，不包含语义结构；由于 q、k、v 相同，部分自身点积与其他点积相等。论文附录的注意力可视化显示，训练后的部分注意力头会关注句法相关的词。

n×n 的打分矩阵意味着序列长度翻倍时，注意力的两两交互计算量约为原来的四倍。论文的对比表将自注意力层记为 O(n2⋅d+n⋅d2)，RNN 层记为 O(n⋅d2)。其中，注意力的 O(n2⋅d) 交互项在 n 小于 d 时低于 RNN 的状态变换项；完整的自注意力层还包括线性投影的 O(n⋅d2) 项。长文本下的平方项是否会成为限制，我当时没有继续分析。

多头注意力使用多组投影

base model 使用 8 个注意力头，dmodel​=512，每个头的 dk​ 和 dv​ 为 64。每个头用独立的 WQ​、WK​、WV​，把 512 维输入线性投影为 64 维的 Q、K、V，独立完成注意力计算。8 个 64 维输出拼接为 512 维，再通过线性层 WO​。这就是多头注意力。

一组 Q/K/V 使用一套匹配标准，多组投影则允许并行学习多套标准。例如，一组可能关注句法主语，另一组可能关注指代对象。附录的可视化中，不同头呈现不同模式：有的集中于相邻位置，有的跨较远位置关注句法成分。8 个头相对于 1 个 512 维头的效果差异需要实验验证；我当时只理解到多组独立投影提供了多种匹配标准。

位置编码提供顺序信息

自注意力有一个需要注意的性质：若不加入位置信息，纯自注意力层对输入位置的置换是等变的。把三个词任意打乱，打分矩阵相应地换行换列，输出也按相同方式重排。因此，「我打狗」和「狗打我」作为词的集合无法被这类层区分。去掉循环结构后，需要通过其他方式加入顺序信息。

论文的方案是位置编码：给每个位置算一个确定的向量，直接加到该位置的词向量上：

PE(pos, 2i)​=sin(100002i/dmodel​pos​)

PE(pos, 2i+1)​=cos(100002i/dmodel​pos​)

pos 是位置序号，i 是维度索引。不同维度对应不同频率的正弦和余弦：低维通道变化较快，高维通道变化较慢。将这些维度组合后，每个位置得到一个位置编码。词向量与位置编码相加后，后续自注意力层接收到的输入包含位置信息。

论文还给了两个说明。其一，对固定偏移量 k，PEpos+k​ 可以表示为 PEpos​ 的线性函数，因此模型可能学习到相对位置。其二，作者也试过可学习的位置 embedding，结果相近，并推测正弦位置编码可以外推到比训练序列更长的位置。第二点我当时可以接受；第一点的推导没有走通。为什么 sin/cos 的组合适合表示相对位置，我当时只读懂了结论。

残差连接与 LayerNorm

原始 Transformer 的编码器和解码器各有 6 层。每个子层（自注意力或前馈网络）都使用残差连接和 LayerNorm。

残差连接的核心形式是 x+Sublayer(x)，即将子层输入加到子层输出上。原始 Transformer 在子层输出和残差相加后再执行 LayerNorm。这个设计来自 ResNet。加法路径为梯度传播提供了直接路径，是深层网络更易优化的工程机制之一。

LayerNorm 对每个位置的隐藏维度计算均值和方差，归一化后再进行可学习的缩放和平移。它不跨 batch 统计数据，因此适合可变长度序列和小 batch 的训练场景。为什么深层网络需要这种归一化，以及 LayerNorm 相对 BatchNorm 的理论差异，我当时只读到工程层面的解释，理论分析没有继续展开。

每层的后半段还有前馈网络：每个位置独立经过一个两层 MLP，在 base model 中从 512 维升到 2048 维，再降回 512 维。该网络在所有位置共享参数，但逐位置计算。我当时将其理解为对每个位置单独做特征变换，没有继续分析升维再降维的设计考量。

编码器、解码器与因果掩码

论文的完整结构是编码器-解码器，用于机器翻译。编码器有 6 层，每层由自注意力和前馈网络组成，将源句编码为带上下文的表示。解码器也有 6 层，每层包含带掩码的自注意力、交叉注意力和前馈网络。交叉注意力中，Q 来自解码器子层的输入，K 和 V 来自编码器输出；解码器据此查询源句的所有位置。

掩码（mask）处理训练阶段的未来词泄露。RNN 的解码状态按时间步递推，因其计算顺序而不能访问未来位置。Transformer 使用 teacher forcing 时，将右移后的目标序列一次输入解码器，各位置可以并行计算。若没有掩码，位置 t 的自注意力会访问位置 t 之后的目标词，从而泄露预测目标。做法是在 softmax 前，将未来位置的打分置为负无穷，e−∞=0，这些位置在 softmax 后的权重为零。这样每个位置只能访问当前位置及之前的位置，因此称为因果掩码。该约束允许并行训练，同时避免访问未来词。

若任务是根据前文预测下一个词，模型不需要编码源句，只保留解码器和因果掩码即可。这条思路后来延伸到 GPT 系列，是下一篇的内容。

待继续理解的问题

LayerNorm 的理论依据、前馈网络升维到 2048 的考量、层数为何取 6，以及注意力机制的表达能力是否有超出实验结果的解释，仍需继续理解。n2 复杂度在长文本中的影响，当时也只停留在论文表格中的比较。
